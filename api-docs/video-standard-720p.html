video-standard-720p · 视频异步 API 接入文档

标准版 720p 视频生成接口。公开模型名为 video-standard-720p，当前仅支持 15 秒任务，支持文生视频及图片、视频、音频参考素材。

POST /v1/videosGET /v1/videos/{task_id}Model: video-standard-720p

1. 创建视频任务

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "video-standard-720p",
    "prompt": "cinematic product commercial, smooth camera movement, high quality 720p",
    "duration": 15,
    "aspect_ratio": "16:9",
    "image_url": "https://your-cdn.com/main-reference.jpg",
    "extra_images": [
      "https://your-cdn.com/ref-1.jpg",
      "https://your-cdn.com/ref-2.jpg"
    ],
    "extra_videos": [
      "https://your-cdn.com/ref-video.mp4"
    ],
    "extra_audios": [
      "https://your-cdn.com/ref-audio.mp3"
    ]
  }'

2. 轮询进度

curl https://xxx.xxx.xxx/v1/videos/task_385412 \
  -H "Authorization: Bearer sk-xxxxxxxx"

3. 创建返回示例

{
  "id": "task_385412",
  "task_id": "task_385412",
  "object": "video.generation",
  "model": "video-standard-720p",
  "status": "in_progress",

5. 查询返回字段

字段说明
id / task_id任务 ID，用于继续查询。
object通常为 video.generation。
model公开模型名，固定为 video-standard-720p。
statusqueued / in_progress / completed / failed。
progress任务进度，0-100；完成时通常为 100。
created_at创建时间戳，单位为秒。
finished_at完成时间戳，单位为秒；未完成时为 null。
video_url / url视频完成后的主结果地址；未完成或失败时为 null。
error失败信息；正常情况下为 null。
output结果数组；完成时通常为 [{"type":"video","url":"..." }]。
result合并后的任务结果对象，包含 task_id、video_url、url、type，也可能透传上游返回字段。

7. 接口参数（PAYLOAD）

参数名类型必填说明
modelstring必填固定 video-standard-720p。
promptstring必填视频内容描述。为空会返回 prompt_required。
duration / secondsinteger / string必填仅支持 15 秒，可传 15 或 15s。其他值会返回 invalid_duration。
aspect_ratio / aspectRatiostring可选默认 16:9。也支持 9:16、1:1 等比例；1280x720 会转为 16:9，720x1280 会转为 9:16。
image_urlstring可选主参考图 URL。也兼容 imageUrl、first_image_url、firstImageUrl、input_reference、inputReference。
extra_imagesarray / string可选参考图 URL 数组。也兼容 extraImages、image_urls、imageUrls、images、reference_images、referenceImages。字符串支持 JSON 数组或逗号分隔 URL。
extra_videosarray / string可选参考视频 URL 数组。也兼容 extraVideos、video_urls、videoUrls、videos。
extra_audiosarray / string可选参考音频 URL 数组。也兼容 extraAudios、audio_urls、audioUrls、audios。
reference_mode / referenceModestring可选参考素材模式；传入时会透传给上游。

8. 状态说明

status含义处理方式
queued排队中继续轮询。
in_progress生成中继续轮询。上游 running / processing / generating 会归一化为此状态。
completed已完成读取 video_url、url 或 output[0].url。
failed失败查看 error.message。
