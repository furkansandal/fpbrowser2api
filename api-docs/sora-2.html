Sora 2 · 视频异步 API 接入文档

支持文生视频和单张参考图生成视频。

提交任务

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sora-2",
    "prompt": "the character turns toward the camera, cinematic lighting",
    "duration": 12,
    "aspect_ratio": "16:9",
    "image": "https://your-cdn.com/portrait.jpg"
  }'

轮询任务

curl https://xxx.xxx.xxx/v1/videos/v_8c7e4b... \
  -H "Authorization: Bearer api-key"

字段

字段类型说明
modelstring固定 sora-2
promptstring提示词
durationint通常为 12 秒
aspect_ratiostring16:9 / 9:16
imagestring单张参考图 URL
