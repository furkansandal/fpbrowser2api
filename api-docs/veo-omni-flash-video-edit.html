VEO Omni Flash Video Edit · 视频编辑接口

基于 1 个参考视频地址进行编辑，可附加参考图片。

! 内容审查避坑提醒：编辑视频前先检查参考视频、图片和提示词 如果返回 didn't pass content review，重试或换账号通常无效，需要改提示词、替换参考视频或替换参考图。 参考视频里的人脸、logo、影视画面也会参与审查 附加参考图要同步避开真人正脸、未成年人和受保护 IP 尽量改成虚构主体、侧背远景或非写实风格后再提交 查看详细页面 →

提交任务

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo-omni-flash-video-edit",
    "prompt": "make the reference video brighter and more cinematic",
    "duration": 10,
    "aspect_ratio": "16:9",
    "video_url": "https://your-cdn.com/reference-video.mp4",
    "Ingredients_images": [
      "https://your-cdn.com/product.jpg"
    ]
  }'

参数

字段说明
model固定 veo-omni-flash-video-edit
video_url必填，只支持 1 个参考视频地址
Ingredients_images可选，参考图片 URL 数组
duration固定 10
aspect_ratio16:9 / 9:16，默认横屏

查询任务

curl https://xxx.xxx.xxx/v1/videos/8c7e4b0e6f3b4b0a9e0a0d8f4f0c1234 \
  -H "Authorization: Bearer api-key"

查询返回字段

字段说明
id / task_id任务 ID，用于继续查询
status / state / task_status任务状态，三者值一致，便于兼容不同中转站
progress进度，0-100
video_url视频任务完成后的主结果地址
url完成后的通用结果地址，视频任务等同于 video_url
metadata.result_urls结果地址数组，通常取第一项即可
seconds / duration任务时长，来自提交参数
aspect_ratio画面比例，来自提交参数
successstatus 为 completed 时为 true
finalcompleted 或 failed 时为 true
error.message失败原因，仅失败时返回

状态说明

status含义处理方式
queued排队中继续轮询
in_progress生成中继续轮询
completed已完成读取 video_url、url 或 metadata.result_urls
failed失败查看 error.message
