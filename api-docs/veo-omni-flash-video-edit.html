VEO Omni Flash Video Edit · 视频编辑接口

基于 1 个参考视频地址进行编辑，可附加参考图片。

提交任务

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo-omni-flash-video-edit",
    "prompt": "make the reference video brighter and more cinematic",
    "duration": 10,
    "aspect_ratio": "16:9",
    "video_url": "https://your-cdn.com/reference-video.mp4",
    "Ingredients_images": [
      "https://your-cdn.com/product.jpg"
    ]
  }'

参数

字段说明
video_url必填，只支持 1 个参考视频地址
Ingredients_images可选，参考图片 URL 数组
duration固定 10
