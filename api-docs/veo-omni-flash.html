VEO Omni Flash · 视频异步 API 接入文档

多参考图生成视频，参考图字段使用 Ingredients_images。

! 内容审查避坑提醒：多参考图提交前尤其要先过一遍 如果返回 didn't pass content review，重试或换账号通常无效，需要改提示词、替换参考图或降低写实人物风险。 逐张检查 Ingredients_images，任意一张高危都可能拒绝 避开真人正脸、未成年人、品牌 logo、动漫影视 IP 优先使用虚构主体、非写实风格、已授权素材 查看详细页面 →

提交任务

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "veo-omni-flash",
    "prompt": "combine these references into a cinematic product launch video",
    "duration": 10,
    "aspect_ratio": "16:9",
    "Ingredients_images": [
      "https://your-cdn.com/ref-1.jpg",
      "https://your-cdn.com/ref-2.jpg"
    ]
  }'

参数

字段说明
model固定 veo-omni-flash
duration固定 10
aspect_ratio16:9 / 9:16，默认横屏
Ingredients_images多参考图 URL 数组，最多 6 张

查询任务

curl https://xxx.xxx.xxx/v1/videos/8c7e4b0e6f3b4b0a9e0a0d8f4f0c1234 \
  -H "Authorization: Bearer api-key"

查询返回字段

字段说明
id / task_id任务 ID，用于继续查询
status / state / task_status任务状态，三者值一致，便于兼容不同中转站
progress进度，0-100
video_url视频任务完成后的主结果地址
url完成后的通用结果地址，视频任务等同于 video_url
metadata.result_urls结果地址数组，通常取第一项即可
seconds / duration任务时长，来自提交参数
aspect_ratio画面比例，来自提交参数
successstatus 为 completed 时为 true
finalcompleted 或 failed 时为 true
error.message失败原因，仅失败时返回

状态说明

status含义处理方式
queued排队中继续轮询
in_progress生成中继续轮询
completed已完成读取 video_url、url 或 metadata.result_urls
failed失败查看 error.message
