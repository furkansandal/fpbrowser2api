video-pro-720p · 视频异步 API 接入文档

高质量版 720p，最高画质档，适合正式成片。提示：云存储文件仅保留 6 小时。超期后物理文件自动清除，但本任务记录永久保留，请及时下载。

POST /v1/videosGET /v1/videos/{task_id}Model: video-pro-720p

1. 创建视频任务

curl -X POST https://xxx.xxx.xxx/v1/videos \
  -H "Authorization: Bearer sk-xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "video-pro-720p",
    "prompt": "cinematic product commercial, smooth camera movement, high quality 720p",
    "duration": 6,
    "aspect_ratio": "16:9",
    "image_url": "https://your-cdn.com/main-reference.jpg",
    "extra_images": [
      "https://your-cdn.com/ref-1.jpg",
      "https://your-cdn.com/ref-2.jpg"
    ],
    "extra_videos": [
      "https://your-cdn.com/ref-video.mp4"
    ],
    "extra_audios": [
      "https://your-cdn.com/ref-audio.mp3"
    ]
  }'

2. 轮询进度

curl /v1/videos/task_385412 \
  -H "Authorization: Bearer sk-xxxxxxxx"

3. 接口参数（PAYLOAD）

参数名类型必填说明
modelstring必填固定值 video-pro-720p
promptstring必填视频内容描述，建议英文。引用素材时在文本中插入 @Image1、@Video1、@Audio1
durationinteger可选视频时长（秒），4-15，默认 6。按秒计费，此即计费单位
aspect_ratiostring可选16:9（默认）、9:16、1:1、21:9、3:4、4:3
image_urlstring可选全能参考图 URL（公网 HTTPS）
extra_imagesarray可选参考图 URL 数组，最多 9 张，用 @Image1 到 @Image9 引用
extra_videosarray可选参考视频 URL 数组，最多 3 个，用 @Video1 到 @Video3 引用
extra_audiosarray可选参考音频 URL 数组，最多 3 个，用 @Audio1 到 @Audio3 引用

4. 状态说明

status含义处理方式
queued排队中继续轮询
processing / in_progress生成中继续轮询
completed已完成读取 video_url 或 url
failed失败查看 error.message
