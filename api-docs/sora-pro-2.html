Sora Pro 2 · 视频任务接口说明

支持文生视频、图生视频、任务查询和鉴权下载。

适用模型

模型说明
sora-vip3-pro-720p适合常规短视频与预览生成
sora-vip3-pro-1080p适合正式交付和高清素材

创建任务

curl -X POST https://your-newapi.com/v1/videos \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sora-vip3-pro-720p",
    "prompt": "rainy neon street, slow cinematic push in",
    "aspect_ratio": "16:9",
    "resolution": "720p",
    "seconds": "5"
  }'

查询与下载

curl https://your-newapi.com/v1/videos/{task_id} \
  -H "Authorization: Bearer YOUR_API_KEY"

curl https://your-newapi.com/v1/videos/{task_id}/content \
  -H "Authorization: Bearer YOUR_API_KEY" \
  --output result.mp4
