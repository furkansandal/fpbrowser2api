FPBrowser2API · Veo / Google Flow

API isteginden browser extension icindeki Flow calistirmasina kadar tum zincir

Python tarafı task kabul eder, pencere ve proje secimini yapar, sonra isi fingerprint browser icindeki extension'a devreder. Gercek submit, upload, reCAPTCHA, poll ve upscale islemleri login olmus `labs.google` oturumunda calisir.

Browser extension

1

Public API

OpenAI / NewAPI uyumlu giris
POST /v1/videos

`veo-3-1`, `veo-omni-flash` ve edit modeli buradan task'a cevrilir.

Payload normalize
  • `duration` dogrulanir
  • `n_frames` set edilir
  • `resolution` 720p / 1080p / 4k olur
Task kaydi

Request DB'ye queued task olarak yazilir ve kullaniciya hemen `task_id` doner.

2

Scheduler & Window

TaskService secimi
task_type_code = veo_workflow

Quota, cooldown, concurrency ve window pool durumuna gore mapping secilir.

Fingerprint window
  • `space_id`
  • `window_key`
  • Roxy / browser base URL
  • proxy, cookie, localStorage
Runtime dispatch

`_run_task` handler'a bakar ve `veo_workflow(...)` fonksiyonunu cagirir.

3

Python Veo Executor

Mode karari
  • `n_frames == 1`: image
  • `Ingredients_images` / `video_url`: r2v
  • `images` / first-last frame: i2v
  • aksi halde: t2v
Project & token hazirligi

`project_id` payload, `veo_url` veya DB'deki `veo_flow_projects` kaydindan bulunur. Session token cache okunur, short token gerekirse extension'dan yenilenir.

Asset lokalizasyonu

Referans gorsel/video URL'leri gerekirse backend tarafinda indirilip browser'in erisecegi lokal asset URL'lerine cevrilir.

4

Extension Bridge

Launcher URL
/#fpb_space_id=...&fpb_window_key=...

Python kisa sure CDP ile kendi launcher sayfasini acar, config'i extension'a verir ve CDP'yi kapatir.

WebSocket register
/api/extension/ws

Extension `hello` mesajiyla `space_id|window_key` anahtarina kaydolur.

Task protokolu
  • `task.start`: ise basla
  • `task.progress`: DB progress
  • `task.done` / `task.error`: final
5

Browser Extension

runVeoTask

`labs.google` project tab'i acilir, sayfa erisimi kontrol edilir, access token ve reCAPTCHA token alinir.

Flow submit
  • T2V: `batchAsyncGenerateVideoText`
  • I2V: start / start-end image
  • R2V: reference images
  • Video edit: uploaded video input
Page context fetch

`pageFetchJson` istekleri MAIN world'de calisir; cookie, user session, proxy ve browser fingerprint korunur.

6

Poll & Result

Status polling
batchCheckAsyncVideoGenerationStatus

Media status ve failure reasons okunur; progress API'ye yansitilir.

Opsiyonel upscale

`resolution=1080p/4k` ise base video uzerinden `batchAsyncGenerateVideoUpsampleVideo` denenir. Fail olursa 720p base result korunur.

Final response

`share_url`, `generated_media_id`, `generated_workflow_id`, `resolution`, `upsample_ok` ve hata bilgileri DB result alanina yazilir.

API yalnizca orkestrator

Gercek Flow istegi server'dan degil, browser extension icinden atilir.

Project zorunlu

`project_id` yoksa payload, URL veya window'a bagli Flow proje listesinden bulunmalidir.

Mode payload'dan cikar

Referans gorsel/video alanlari T2V, I2V ve R2V ayrimini belirler.

Token iki katmanli

Long session token DB'de cache'lenir, short access token Flow sayfasindan tazelenir.

Browser guveni kullanilir

Cookie, proxy, localStorage, reCAPTCHA ve fingerprint pencereye aittir.

Upscale best-effort

1080p/4K basarisiz olursa task komple fail olmaz; base video doner.

Kisa mental model

FPBrowser2API bir "browser-backed API gateway" gibi calisir: API task'i olusturur, Python dogru pencereyi secer, extension ise Google Flow'u login olmus gercek browser oturumunda calistirir.
